# 2.3.0

## Added

- `event-observer-state`, migrated from Arch Toolkit with package
  `br.com.arch.toolkit.eventObserver.state` and the repository's KMP targets.
- Serializable saved screen state, plain/result operation binding, transformation, reduction,
  latest-operation cancellation and read-through projections.
- Restoration and operation regression tests, including Android SavedStateRegistry parcel round trips.
- Worker execution for producers, transformations and codec preparation; `setAsync` and `selectAsync`.
- Large-list and real-executor responsiveness regression tests, plus decoded snapshot reuse.
- Module coverage floors: 90% lines, 85% instructions and 80% branches.

## Corrected in the migrated module

- Defaults no longer overwrite restored data; saved null remains distinct from absence.
- One-shot completion no longer controls state lifetime; refresh starts another operation.
- State observation remains connected after clearing; JSON is the single saved representation.
- Restored result payloads become Success, with loading/errors kept transient.
- Koin, Lumber and Splinter are no longer dependencies of the state module.

The base and Compose artifacts keep their public APIs. See [migration](../migration-state.md)
for state-module changes and the old/new coordinates. Publication is confirmed by the release tag.
