# 2.3.1

Maintenance changes based on tag `2.3.0`.

## Changes

- Refactor `ComposableDataResult.Unwrap` in `event-observer-compose` to use `AnimatedContent`, enabling unified state transitions (`ContentTransform`) across `DataResult` states.
- Introduce `contentTransform: ContentTransform?` in `ComposableDataResult.AnimationConfig` for custom enter/exit transitions (slide, scale, fade) or disabling animations by setting `null`.
- Add `modifier: Modifier = Modifier` parameter to `ComposableDataResult.Unwrap` to support layout modifiers (padding, sizing, etc.) directly on the root container.
- Optimize Compose rendering performance in `Unwrap` by eliminating `Iterator` allocations in list iterations and memoizing DSL configurations via `remember(config)`.
- Add `ComposableDataResultAnimationTest` suite in `event-observer-compose` and update module documentation and recipes.

- Update Android Gradle Plugin from 9.4.0 to the stable 9.4.1 patch.

- Update Android SDK setup to `android-actions/setup-android@v4` (Node 24 and the maintained command-line tools provided by the action), explicitly installing `platform-tools` instead of the unavailable legacy `tools` package.

- Apply one generated-class filter to module reports and root coverage aggregation, including HTML, XML and verification.
- Disable Codecov report discovery so only `build/reports/kover/report.xml` is uploaded; module reports cannot reintroduce excluded classes.
- Exclude only Android-generated `BuildConfig`, `R` and nested `R` classes; retain handwritten code and existing coverage floors.
- Configure Android test JVM access required by Robolectric 4.17 on JDK 21.
- Update the GitHub App token action to v3 (Node 24 on hosted runners).
- Use this versioned changelog directly for the GitHub Release, without a duplicate root notes file.
- Document coverage scope, local commands and the audited dependency versions.
- Refresh the JavaScript Yarn lockfile for Kotlin 2.4.20's tooling dependencies.
- Update MkDocs Material from 9.7.6 to 9.7.7.
- Verify the existing Gradle 9.7.1 distribution with its official SHA-256 checksum.

## Compatibility

Adds non-breaking API extensions to `event-observer-compose` (`Unwrap(modifier)` default parameter and `contentTransform` in `AnimationConfig`). Existing minimum Android SDK and KMP targets remain unchanged.
Coverage measures JVM/Android host tests; Apple, JS and Wasm tests remain in the test suite but do not contribute coverage counters.

Dependencies on other Arch repositories use versions available in Maven Central, rather than unpublished patch candidates.
