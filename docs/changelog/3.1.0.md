# 3.1.0

Planned release based on published 3.0.0; additive API, no intended breaking change.

- Add `DataResult.unwrap(scope, transformDispatcher, config)` to configure execution
  per observation without mutating the result. Existing setters remain supported.
- Document that equality/copy use constructor values only and that `copy()` and
  `transform()` do not propagate legacy execution settings.
- Limit sequence emptiness checks to one iterator probe and cardinality checks to
  two elements. Tail side effects/errors are no longer evaluated by shape checks.
  Constrained-once sequences remain single use; no replay/cache is added.
- Explain result snapshots, application events and persisted state with core,
  Compose and state examples, including cancellation and restoration boundaries.
- Add common tests for value/execution contracts and bounded sequence inspection.
